## 🌐 **Deployment Opcije:**

### **Option 1: Vercel (Priporočeno)**
```bash
# Namestite Vercel CLI
npm i -g vercel

# Deploy iz projekta
cd /Users/isakzvegelj/isak-projects/organized-projects/development-tools/projects/web-development/omerzel-gallery
vercel

# Sledite navodilom za povezavo z GitHub in deployment
```

### **Option 2: Netlify**
1. Push kode v GitHub repository
2. Povežite Netlify z vašim GitHub repo
3. Build nastavitve:
   - Build command: `npm run build`
   - Publish directory: `.next`

### **Option 3: Traditional Hosting**
- Upload `.next` folder na vaš web server
- Zagotovite Node.js 18+
- Zaženite `npm start` v produkciji
